# Advanced_ET_scanner
Lightweight project for getting back into C programming and learning ESP32 development

Made to run on ESP32 with ESP-IDF 5.5:<br>
check device manager and find used port for connected ESP32<br>

enter download mode:<br>
idf.py build<br>
hold BOOT on ESP32<br>
press RESET on ESP32<br>
run idf.py -p COM1 flash<br>
wait until flash is initialized<br>
release BOOT on ESP32
